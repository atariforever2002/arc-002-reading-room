# ARC-002 — The Reading Room

**Arcade Side B — The Overlooked Side of Arcade History**

The Reading Room is a curated English-language arcade-history clubhouse organized around **READ • NEWS • WATCH • LISTEN • PLAY • RESEARCH**. It combines period magazines and trade press with modern retrospective reading, current arcade news, creator oral histories, classic-game postmortems, playable preservation, developer/company research, and workshop references.

**Live site:** https://atariforever2002.github.io/arc-002-reading-room/

The site is maintained as a lightweight static GitHub Pages project.
